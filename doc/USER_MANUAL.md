# Folder Deck 사용자 매뉴얼

대상 버전: 1.7.0 · Windows x64

Folder Deck는 여러 폴더를 한 화면의 타일에 펼쳐 놓고 탐색·복사·이동·검색하는 데스크톱 앱입니다. 자주 사용하는 폴더를 작업 관리(워크스페이스)로 묶고, 각 타일의 위치와 보기 설정을 저장할 수 있습니다.

## 1. 설치와 첫 실행

1. 설치 파일 `FolderDeck-Setup.exe`를 실행합니다. 현재 사용자 계정에 설치됩니다.
2. 시작 메뉴에서 **Folder Deck**를 실행합니다. 자체 포함 배포본은 .NET 런타임을 별도로 설치하지 않아도 됩니다.
3. 작업 관리 목록에서 **＋ 새 작업 공간**을 누르고 제목과 폴더를 등록합니다. 폴더를 목록 창에 끌어다 놓아 시작할 수도 있습니다.
4. 카드를 더블클릭하거나 **열기**를 누르면 해당 작업 화면으로 전환됩니다.

설치 파일은 소스 저장소와 별도로 배포됩니다. 소스만 받은 경우 루트 README의 빌드 안내를 따르세요.

작업 관리 카드에서 제목과 설명을 수정할 수 있습니다. **삭제**는 작업 관리 등록만 제거하며 실제 파일과 폴더는 삭제하지 않습니다. 이미 열린 작업 관리에는 **열려 있음**이 표시됩니다.

**마지막 작업을 자동으로 열기**를 켜면 다음 실행부터 마지막 작업 관리로 바로 들어갑니다. 메인 도구모음의 **다른 작업 관리 열기**로 목록 창을 열어 다른 작업 관리를 함께 사용할 수 있습니다.

## 2. 화면과 타일

왼쪽에는 등록한 폴더 목록과 복사 대상함·매크로가 있고, 오른쪽에는 4×4 배치 그리드가 있습니다. 타일 하나가 폴더 탐색기 하나이며, 서로 다른 폴더를 동시에 보여줍니다. 왼쪽 패널은 접었다 펼 수 있습니다.

- **상시 칸**: 특정 등록 폴더를 계속 표시하는 자리입니다. 하위 폴더로 이동할 수 있습니다.
- **순환 칸**: 왼쪽 목록에서 선택한 폴더를 바꿔 표시하는 자리입니다. 여러 순환 칸이 있으면 폴더 행의 우클릭 메뉴에서 사용할 칸을 지정합니다.
- **앵커**: 타일이 돌아갈 기준 폴더입니다. **앵커 복귀** 또는 `Alt+Home`으로 돌아갑니다.

왼쪽 목록에서 상시 칸에 등록된 폴더를 누르면 해당 타일이 앵커로 돌아갑니다. 타일의 헤더에서 뒤로·앞으로·상위·앵커 복귀·새로 읽기를 사용할 수 있습니다. 폭이 좁으면 일부 기능은 **⋯ 더 보기** 메뉴에 들어갑니다. 타일 확장 버튼으로 작업 영역을 넓히고 다시 복귀할 수 있습니다.

## 3. 폴더 등록과 배치 편집

- 폴더 목록 머리의 **＋**로 폴더를 등록합니다.
- 행의 **✕** 또는 우클릭 **제거**는 등록만 제거합니다. 디스크의 폴더는 남습니다.
- 행의 우클릭 메뉴에서 표시 이름·설명을 수정하거나 대상함에 추가할 수 있습니다.
- 타일의 경로 영역을 우클릭하면 **새 폴더 만들기**, **탐색기에서 열기**, **경로 복사**, **이 폴더를 앵커로 지정**, **새 폴더로 등록**을 사용할 수 있습니다.

메인 도구모음에서 **배치 편집**을 켜면 타일을 이동하고 크기를 조절할 수 있습니다. 편집 중에는 파일 목록 조작이 잠깁니다. 빈 그리드 영역에 타일을 배치하고 상시·순환 용도를 지정한 뒤 편집을 종료합니다. 타일 사이 간격도 조절할 수 있습니다. 확장된 타일을 먼저 복귀해야 배치 편집을 할 수 있습니다.

## 4. 보기·정렬·미리보기

일반 폴더 타일의 보기 전환 버튼은 **목록 → 상세 → 큰 아이콘 → 아주 큰 아이콘 → 목록** 순서로 동작합니다. 보기 전환 시 선택한 항목은 해제됩니다. 검색 전용 타일은 상세 보기로 표시됩니다.

정렬 메뉴에서 이름·수정 시각·크기·종류와 **폴더 먼저**를 선택합니다. 상세 보기에서는 열 머리글로 정렬하고 같은 열을 다시 눌러 방향을 바꿀 수 있습니다. 정렬 변경은 선택을 유지합니다. 열 표시 메뉴로 크기·수정·위치 열을 조절할 수 있습니다.

미리보기를 켜고 항목을 선택하면 타일 아래에서 내용을 확인합니다. 표시 가능한 형식은 Windows에 설치된 Preview Handler와 앱의 이미지 미리보기 지원에 따라 달라집니다. 지원하지 않는 파일에는 안내 문구가 나타납니다. 구분선을 끌어 미리보기 영역 크기를 조절합니다.

**설정**에서 셸 아이콘 사용 여부와 확장자별 글리프를 바꿀 수 있습니다. 클라우드 전용 파일이나 인터넷에서 받은 파일은 내려받기 상태·보안 표시 등에 따라 미리보기가 제한될 수 있습니다.

## 5. 파일 열기·선택·이름 변경·삭제

파일은 더블클릭하면 기본 프로그램으로 열리고 폴더는 타일 안에서 열립니다. `Ctrl`과 `Shift`를 사용해 여러 항목을 선택할 수 있습니다. 우클릭하면 Windows 셸 메뉴와 Folder Deck 기능을 사용할 수 있습니다.

- `F2`: 선택한 항목 하나의 이름을 변경합니다.
- `Ctrl+Shift+N`: 현재 폴더에 새 폴더를 만듭니다.
- `Delete`: 선택한 항목을 휴지통으로 보냅니다. 삭제 확인 내용을 확인하세요.
- `Shift+Delete`: 영구 삭제를 실행하지 않고 거절 안내를 표시합니다.

등록 제거와 디스크 삭제는 별개입니다. 네트워크 경로 등 휴지통을 사용할 수 없는 대상은 작업이 거절되거나 실패할 수 있습니다. 상태 바의 결과를 확인하세요.

## 6. 복사·이동·대상함·매크로

`Ctrl+C`는 복사, `Ctrl+X`는 잘라내기, 대상 타일에서 `Ctrl+V`는 붙여넣기입니다. 타일 사이 또는 Windows 탐색기와의 끌어놓기도 지원합니다. 표시되는 복사·이동 동작을 확인한 뒤 놓으세요. 같은 폴더에 복사하면 사본 이름을 사용합니다.

복사 대상함에 폴더를 추가하고 대상 폴더를 체크하면 여러 목적지로 복사하는 작업을 준비할 수 있습니다. 이동은 목적지가 하나여야 합니다. 같은 이름이 있을 때는 **덮어쓰기**, **건너뛰기**, **둘 다 두기** 중에서 처리 방법을 선택합니다.

처리 중에는 상태 바에 진행 상황이 표시됩니다. 취소는 이미 끝난 작업을 되돌리지 않습니다. 결과 메시지와 목적지 파일을 확인하세요.

매크로는 반복할 복사·이동·휴지통 작업의 규칙을 저장합니다. 편집 창의 **고급 옵션**에서 실행 시 선택한 파일을 사용할지, 고정한 파일을 사용할지, 대상함의 체크 상태를 따를지 등을 정합니다. 실행 전 미리보기 옵션으로 원본·대상·충돌 처리를 확인할 수 있습니다.

## 7. 검색

`Ctrl+F`로 현재 타일의 검색 입력칸을 엽니다. 일반 폴더 검색은 이름의 부분 일치로 검색하며 대소문자를 구분하지 않습니다. 하위 폴더 검색을 켜면 현재 폴더 아래를 재귀로 검색합니다. 검색을 닫으면 일반 폴더 목록으로 돌아갑니다.

전역 검색은 Everything 연동을 사용합니다. Everything 프로그램이 별도로 설치되고 실행 중이어야 하며, 배포본의 `Everything64.dll`만으로 검색 인덱스를 만들지는 않습니다. **설정 → 검색**에서 연동 상태와 결과 상한을 확인하세요. Everything이 없거나 연결되지 않으면 전역 검색을 사용할 수 없습니다. 일반 폴더 검색은 별도로 사용할 수 있습니다.

## 8. 폴더 비교·내용 비교·중복 찾기·배치 리네임

**타일 간 비교**: 폴더 타일에서 `Ctrl+D`를 누르고 상대 타일을 선택합니다. 파일 이름은 대소문자 구분 없이 짝지으며 **같음**, **다름**, **여기만** 배지를 표시합니다.

**같음**은 파일의 이름·크기·수정 시각이 같다는 뜻입니다. 파일 내용의 바이트 일치를 보장하지 않습니다. 같은 이름의 폴더는 존재 여부만 비교하며 하위 폴더를 재귀 비교하지 않습니다.

**내용 비교**: 비교된 파일의 우클릭 **내용 비교**를 사용합니다. 텍스트를 나란히 보여주고 달라진 부분을 강조합니다. 양쪽은 가로 스크롤을 따로, 세로 스크롤을 함께 사용합니다. 파일 경로를 클릭하면 기본 프로그램으로 엽니다. 텍스트 파일당 최대 5MB를 지원하며 이진 파일은 거절합니다. BOM·UTF-8·CP949를 처리하지만 다른 인코딩은 문자가 잘못 보일 수 있습니다.

**중복 찾기**: 도구모음에서 실행하면 현재 열린 타일의 파일 중 이름·크기가 같은 항목을 묶습니다. 내용 해시를 비교하지 않으므로 중복 후보로 판단하세요. 결과를 더블클릭하면 탐색기에서 파일 위치를 엽니다.

**배치 리네임**: 파일을 여러 개 선택하고 `Ctrl+F2`를 누릅니다. 찾기/바꾸기·번호 매기기·대소문자 변환 규칙을 선택한 뒤 새 이름 미리보기를 확인합니다. 이름 충돌이나 사용할 수 없는 이름을 먼저 해결하고 실행하세요.

## 9. 단축키

| 단축키 | 동작 |
| --- | --- |
| `Alt+←` / `Alt+→` | 타일의 뒤로 / 앞으로 |
| `Alt+↑` | 상위 폴더 |
| `Alt+Home` | 앵커 폴더 복귀 |
| `F5` | 열린 폴더 목록 새로 읽기 |
| `Ctrl+F` | 현재 타일 검색 입력 |
| `F2` | 이름 변경 |
| `Ctrl+F2` | 배치 리네임 |
| `Ctrl+D` | 상대 타일과 목록 비교 |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 복사 / 잘라내기 / 붙여넣기 |
| `Ctrl+Shift+N` | 새 폴더 만들기 |
| `Delete` | 휴지통으로 삭제 |

타일에 포커스가 있어야 해당 타일의 단축키가 적용됩니다. 검색·이름 입력 중에는 텍스트 편집에 사용하는 키가 우선할 수 있습니다.

## 10. 저장 위치·백업·문제 해결

- 설치 위치: `%LOCALAPPDATA%\FolderDeck\app`
- 사용자 데이터: `%APPDATA%\FolderDeck`
- 전역 설정: `settings.json`
- 작업 관리: `workspaces\{id}.json`

백업하려면 모든 Folder Deck 창을 닫고 사용자 데이터 폴더를 복사하세요. 복원할 때도 앱을 종료한 뒤 복원합니다. 작업 관리에는 실제 폴더 경로가 저장되므로 다른 PC로 옮기면 해당 경로를 맞추거나 폴더를 다시 등록해야 합니다. 이 데이터는 개인 백업으로 관리하고 공개 저장소에 올리지 마세요.

폴더가 열리지 않으면 경로 존재 여부·권한·네트워크 연결을 확인한 뒤 `F5`를 누르세요. 접근 불가 폴더는 자동으로 등록에서 지워지지 않습니다. 파일 목록이 갱신되지 않으면 창을 다시 활성화하거나 `F5`로 새로 읽으세요.

전역 검색 실패는 Everything 실행 상태와 설정 화면의 연동 상태를 확인하세요. 미리보기 실패는 파일 형식·로컬 다운로드 상태·Preview Handler 지원 여부를 확인하세요. 저장 실패나 손상 데이터 안내가 나오면 해당 JSON을 백업하고 상태 메시지를 확인한 뒤 복구하세요.
