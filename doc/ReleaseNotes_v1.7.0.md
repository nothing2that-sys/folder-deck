# FolderDeck v1.7.0 (2026-09-18 ~ 09-21)

## 추가된 기능

**타일 간 비교 (Ctrl+D)**
타일(폴더) 하나를 고르고 `Ctrl+D`를 누르면 비교할 상대 타일을 고를 수 있습니다. 두
타일의 파일 목록을 이름 기준으로 대조해 각 줄에 배지를 붙입니다 — `[같음]`(이름·크기·
수정 시각까지 같음) · `[다름]`(이름은 같은데 내용이 다름) · `[여기만]`(상대에는 없음).

**내용 비교 (우클릭 → "내용 비교")**
`[다름]`으로 표시된 파일을 우클릭하면 두 파일의 실제 내용을 나란히 비교하는 창이
뜹니다. 바뀐 줄은 줄 전체가 아니라 실제로 달라진 단어만 노랗게 표시됩니다. 위쪽 경로를
클릭하면 그 파일이 바로 열립니다. 좌우 패널은 각자 가로 스크롤(세로는 같이 움직임)이고,
가운데 구분선을 끌어 폭을 조절할 수 있습니다.

**워크스페이스 내 중복 파일 찾기 (도구모음 "중복 찾기")**
지금 열려 있는 모든 타일을 훑어 이름·크기가 같은 파일을 묶어 표로 보여줍니다.
더블클릭하면 탐색기에서 그 파일 위치를 엽니다.

**배치 리네임 (Ctrl+F2)**
여러 파일을 한 번에 규칙(찾기/바꾸기·번호 매기기·대소문자 변환)으로 이름을 바꿉니다.
바뀔 이름을 미리 보고, 충돌이 있으면 실행 전에 알려줍니다.

## 고친 것

- 스크롤 중인 항목이 아이콘을 불러오는 동안 뒤쪽 항목들의 로딩을 막던 문제
- PDF·TXT 미리보기가 실제로는 격리 실행되지 않던 문제
- OneDrive 등 클라우드 동기화 표시 파일이 검색에서 빠지던 오탐
- 목록 보기(기본 화면)에서 타일 비교 배지가 아예 안 보이던 문제
- `Ctrl+F2`로 배치 리네임 창을 열면 매번 나던 크래시
- 비교 상대 타일을 고르는 창에서, 목록을 직접 클릭하지 않고 바로 확인을 누르면 조용히
  취소되던 문제
- 타일 비교 직후 배지가 잠깐 떴다가 곧바로 사라지던 문제

## 그 외 개선

- 중복 찾기 화면을 표 형태로 다시 설계해 더 읽기 쉬워짐
- 완전히 같은 파일도 `[같음]` 배지로 표시(전에는 비교 대상인지 아닌지 구분이 안 됐음)
