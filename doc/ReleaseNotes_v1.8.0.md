# FolderDeck v1.8.0 (2026-10-14)

## 추가된 기능

**1회용 창 (단축키 `Ctrl+Alt+F`)**
윈도우 탐색기처럼 단축키 한 번으로 바로 뜨는 탐색기 창입니다. 닫으면 끝나고 아무것도 저장되지
않습니다. 여러 개를 동시에 띄울 수 있습니다. 시작 메뉴의 「Folder Deck 1회용」으로도 띄울 수
있습니다.
- 타일 배치를 고를 수 있습니다 — 1개 전체 · 좌우 · 상하 · 4개. 처음 배치는 설정 → 「1회용 창」
  탭에서, 띄운 뒤에는 오른쪽 위 `⋯` → 「타일 배치」에서 바꿉니다. 떠 있던 폴더는 새 배치로 옮겨
  담깁니다.
- 1회용 창에는 앵커가 없습니다. 하위 폴더로 들어가도 「앵커 밖」 표시가 뜨지 않고, 경로는 늘
  드라이브부터 보입니다.

**단축키 상주 프로그램 (트레이)**
설치하면 FolderDeck 가 작업 표시줄 오른쪽 트레이에 남아 1회용 창 단축키를 받습니다. 이미 떠 있는
프로그램이 창만 열기 때문에 단축키를 누르자마자 뜹니다.
- 로그인할 때 자동으로 시작합니다.
- 트레이 아이콘 더블클릭 = 1회용 창 열기. 우클릭하면 「작업 관리 열기」·「상주 끝내기」가 있습니다.
- 상주를 끝내도 단축키는 계속 동작합니다. 그때는 조금 느리게 뜨고, 그 실행이 상주를 다시
  띄웁니다.
- 단축키는 설정 → 「1회용 창」 탭에서 바꿀 수 있습니다(`Ctrl+Alt` 또는 `Ctrl+Alt+Shift` + 영문자 ·
  숫자 · F1~F12, 또는 「없음」). 다른 프로그램이 이미 쓰는 키면 트레이 알림으로 알려줍니다.
- 상주 프로그램을 쓰고 싶지 않으면 같은 탭의 「상주 프로그램으로 받기」를 끄세요. 그러면 시작 메뉴
  바로가기가 단축키를 받습니다(상주는 없지만 뜨기까지 몇 초 걸릴 수 있습니다).

**즐겨찾기 (모든 작업 관리 공유)**
왼쪽 패널 맨 위에 「즐겨찾기」가 생겼습니다. 여기 넣은 폴더는 모든 작업 관리 창에서 함께 보이고,
한 창에서 추가·삭제하면 열려 있는 다른 창에도 곧 반영됩니다.
- 추가: 묶음 헤더의 `＋`, 폴더 우클릭 「즐겨찾기에 추가」, 경로 표시줄 우클릭 「즐겨찾기에 추가」.
- 클릭하면 **마지막으로 클릭한 타일**(위쪽에 파란 선)이 그 폴더로 이동합니다. 작업 관리에 등록된
  폴더나 배치는 바뀌지 않습니다.
- 우클릭: 위로 · 아래로 · 등록 폴더로 추가 · 제거. 지금 열 수 없는 폴더는 흐리게 보입니다.

## 바뀐 것

- 오른쪽 위의 「중복 찾기」·「설정」·「다른 작업 관리 열기」 버튼을 `⋯` 메뉴 하나로 모았습니다.
  「배치 편집」은 작은 「✎ 배치」 토글로 남았습니다.

## 알아 두실 것

- 이 판은 설정 파일 형식이 바뀌었습니다. 이 판을 쓴 뒤 **이전 판(1.7.0 이하)으로 되돌리면 설정을
  읽지 못하고** 설정 변경이 저장되지 않는 상태로 뜹니다. 되돌릴 생각이 있으면 설치 전에
  `%APPDATA%\FolderDeck\settings.json` 을 따로 보관해 두세요.
- 설치 파일이 이전보다 약 7 MB 커졌습니다(트레이 아이콘에 쓰는 부품이 함께 들어갑니다).
